# ข้อมูลผู้เล่น

ระบบมีผู้เล่นเริ่มต้น 5 คน

| Player ID | ชื่อ | Potion | Arrow | Bomb |
|:----------|:-----|-------:|------:|-----:|
| `0007` | Mew | 3 | 240 | 2 |
| `0124` | Win | 5 | 80 | 1 |
| `1050` | Nara | 1 | 130 | 4 |
| `0420` | Fai | 0 | 300 | 2 |
| `9001` | Tin | 6 | 40 | 0 |

**ข้อสำคัญ:** `Player ID` ต้องเก็บเป็น `string`

เช่น

```text
0007
```

ต้องยังเก็บเป็น

```python
"0007"
```

ห้ามกลายเป็น

```text
7
```

ให้ออกแบบการเก็บข้อมูลผู้เล่นทั้งหมดโดยใช้ `dict`

# 1. เข้าสู่ระบบผู้เล่น

เมื่อเริ่มโปรแกรม ให้ผู้ใช้กรอก

```text
Player ID:
```

โปรแกรมต้องตรวจสอบว่า Player ID ที่กรอกเข้ามามีอยู่ในระบบหรือไม่

ถ้าไม่มี ให้แสดงข้อความ เช่น

```text
ไม่พบผู้เล่น
```

แล้วให้กรอกใหม่

ถ้าพบ Player ID ให้เข้าสู่เมนูหลักของผู้เล่นคนนั้น

ตัวอย่าง

```text
Player ID: 0007

เข้าสู่ระบบสำเร็จ
สวัสดี Mew
```

---

# 2. เมนูหลัก

เมื่อเข้าสู่ระบบสำเร็จ ให้แสดงเมนู

```text
===== ADVENTURE INVENTORY =====

1. ดูไอเท็มของฉัน
2. รับไอเท็มเพิ่ม
3. ใช้ไอเท็ม
4. ส่งไอเท็มให้ผู้เล่นอื่น

เลือกเมนู:
```

หลังจากทำแต่ละรายการเสร็จแล้ว โปรแกรมต้องกลับมาแสดงเมนูหลักอีกครั้ง

และยังคงเป็นผู้เล่นคนเดิม

ยกเว้นกรณีเลือก

```text
6. เปลี่ยนผู้เล่น
```

หรือ

```text
7. ออกจากโปรแกรม
```

# 4. รับไอเท็มเพิ่ม

ให้ผู้เล่นเลือกไอเท็มที่ต้องการรับ


# 8. เตรียมลูกธนูออกเดินทาง

ผู้เล่นสามารถนำ Arrow ออกจาก Inventory เพื่อใช้ในการเดินทางได้

Arrow ต้องจัดเป็นมัดตามขนาดต่อไปนี้

```text
100 ดอก
50 ดอก
10 ดอก
```

ให้ผู้เล่นกรอกจำนวน Arrow ที่ต้องการนำออกเดินทาง

ตัวอย่าง

```text
จำนวน Arrow ที่ต้องการนำไป:
```

---

## เงื่อนไข

จำนวน Arrow ที่กรอกต้อง

1. มากกว่า `0`
2. ไม่เกินจำนวน Arrow ที่ผู้เล่นมี
3. หาร `10` ลงตัว

ถ้าเงื่อนไขไม่ถูกต้อง

**ห้ามหัก Arrow ออกจาก Inventory**

---

## ตัวอย่าง

ผู้เล่นต้องการนำ Arrow

```text
180
```

โปรแกรมต้องจัดมัดใหญ่ที่สุดก่อน

ผลลัพธ์

```text
Arrow 100 = 1 มัด
Arrow 50  = 1 มัด
Arrow 10  = 3 มัด

รวม = 180 ดอก
```

จากนั้นจึงหัก Arrow ออกจาก Inventory

---

ตัวอย่าง

ก่อนนำออก

```text
Arrow = 240
```

นำไป

```text
180
```

หลังจากทำรายการสำเร็จ

```text
Arrow คงเหลือ = 60
```

# 10. Function

โปรแกรมต้องมีการแยก Function ตามหน้าที่

ไม่ควรเขียนทุกอย่างรวมกันอยู่ในส่วนเดียว

ตัวอย่างหน้าที่ที่ควรแยก เช่น

```text
แสดงเมนู
แสดง Inventory
รับไอเท็ม
ใช้ไอเท็ม
ส่งไอเท็ม
เตรียมลูกธนู
```

นักเรียนสามารถออกแบบชื่อ Function เองได้

ตัวอย่างชื่อ

```python
show_menu()
show_inventory()
receive_item()
use_item()
transfer_item()
prepare_arrow()
```

**ชื่อด้านบนเป็นเพียงตัวอย่าง**

ไม่จำเป็นต้องตั้งชื่อตามนี้

สิ่งสำคัญคือต้องเข้าใจว่าแต่ละ Function มีหน้าที่อะไร

# 🎯 เป้าหมายของโจทย์

โจทย์นี้ไม่ได้วัดว่า

> **จำ Code เก่าได้หรือไม่**

และไม่ได้วัดว่า

> **สามารถให้ AI ทำโปรแกรมให้ได้หรือไม่**

แต่ต้องการทบทวนว่านักเรียนสามารถ

1. อ่าน Requirement
2. แยกปัญหาออกเป็นส่วนย่อย
3. เลือก Data Type ให้เหมาะสม
4. รับข้อมูลจากผู้ใช้
5. ตรวจสอบเงื่อนไข
6. ใช้ Loop
7. ใช้ `dict`
8. แก้ไขข้อมูล
9. แยก Function
10. ตรวจสอบข้อมูลก่อนเปลี่ยน State
11. Debug ปัญหาพื้นฐาน
12. อธิบาย Code ของตัวเอง

ได้หรือไม่

ภาพรวมของเนื้อหาที่ต้องการทบทวนคือ

```text
Variable
   ↓
Data Type
   ↓
Input / Output
   ↓
Condition
   ↓
Loop
   ↓
Calculation
   ↓
Dictionary
   ↓
Function
   ↓
Validation
   ↓
Update State
```

AI สามารถช่วยอธิบายสิ่งที่ยังไม่เข้าใจได้

แต่สุดท้าย

> **เจ้าของ Code ต้องสามารถอธิบาย Code ของตัวเองได้ทุกส่วน**

และ

> **คำถามทุกข้อที่ตัวเองถาม AI ต้องสามารถตอบได้เมื่อผู้สอนถาม**
